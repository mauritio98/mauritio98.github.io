What I fixed

1. Viewport
Page shown as a tiny desktop site on phones
Added the viewport meta tag
2. Page width
Fixed 1200px width, sideways scrolling
Flexible container with a max width
3. Navigation
Links overflowing the screen
Mobile menu with a working ☰ button
4. Typography
Huge fixed font sizes
Fluid sizes with CSS clamp()
5. Buttons
Different sizes and misaligned
Same style, aligned with flexbox
6. Product cards
Floated boxes breaking the layout
CSS grid: 3 columns on desktop, 1 on mobile
7. Contact form
JavaScript error, page reloads, no message
Fixed the bug, added validation and a confirmation
